# Roadmap

## Phase 1 (core)
Incident management, alert webhook, failure simulation, LangGraph investigation with real
tools, recovery engine (restart / rollback / scale), human approval, verification, audit log,
dashboard, Docker Compose, Kubernetes manifests, tests.

## Phase 2 backlog (not prioritised until Phase 1 works end to end)
- Multi-agent investigation
- RAG over incident runbooks
- Similar incident retrieval
- Advanced root-cause analysis
- Anomaly detection
- Advanced canary analysis
- AWS deployment
- Terraform
- GitHub Actions CI/CD
- Multi-service dependency graph
- Slack integration
- Advanced distributed tracing
- Incident prediction
- Advanced role-based access control
